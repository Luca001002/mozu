# MOZU

> ⚠️ **現在は限定テスト配布中です。** 知人向けに動作を確かめてもらっている段階で、一般公開はしていません。予告なく仕様が変わることがあります。

**「さっきの瞬間」を、あとから保存する。** Windows 用のインスタントリプレイ＆スクショツールです。

直近数分の映像をメモリ上に記録しておき、ショートカットキーを押した瞬間にクリップとして保存します。
SSD には保存した瞬間しか書き込みません。

ゲームに限らず、画面に映っているものなら何でも残せます。

このリポジトリは **配布専用** です(インストーラーと更新情報のみを置いています。ソースコードは含みません)。

## これ 1 本でできること

| | |
|---|---|
| **インスタントリプレイ** | 直近 1〜10 分をメモリに保持。キーを押した瞬間だけ MP4 として書き出します |
| **スクショ** | 全画面と範囲選択。撮った瞬間にクリップボードへ入るので、そのまま Ctrl+V |
| **一覧** | クリップとスクショを 1 つの画面で。★・リネーム・まとめて削除・複数選択 |
| **軽い編集** | いるところだけ切り出す・画面の一部を切り抜く・複数クリップを 1 本に結合・BGM を重ねる |
| **SNS 用の書き出し** | Discord の 20MB・X の 140 秒に合わせてワンボタンで圧縮。書き出したファイルは自動でコピーされます |

録画してから共有するまでが 1 つのアプリで完結します。別の変換ソフトや編集ソフトを開く必要はありません。

## Discord と X に投げるのがラクです

どちらも**ボタン 1 つ**です。**書き出したファイルは自動でクリップボードに入る**ので、戻って **Ctrl+V** するだけで添付できます。

**Discord** — 20MB の制限に収まるよう自動で圧縮します。

- 長さから逆算して画質を決めるので、**「20MB を超えました」と突き返されることがありません**。目安は 3 分までなら 720p、6 分までなら 480p
- 6 分を超えるクリップは、画質が落ちすぎて中身が分からなくなるため**あえて断ります**。代わりに「収まる長さに詰める」ボタンが出ます
- **もともと 20MB に収まっているクリップは、圧縮せずそのまま**使います。無駄に画質を落としません
- **Discord Nitro に加入しているなら**、設定の「共有」でプランを選んでください。50MB / 500MB の上限いっぱいまで使って、より高画質に書き出します
- 一覧から複数選択して**まとめてドラッグ**すれば、何本でも一度に添付できます

**X** — 1080p・140 秒(無料アカウントの上限)に自動で合わせます。

- すでに条件を満たしているクリップは、こちらも**変換せずそのまま**コピーします
- 140 秒(無料アカウントの上限)を超えている場合は、その旨を添えて書き出します。長さの調整は編集画面のタイムラインでできます
- **X プレミアムに加入しているなら**、設定の「共有」で選んでください。140 秒の案内が消え、プランの上限まで長い動画をそのまま扱えます

「クリップを保存 → 別ソフトで圧縮 → ファイルを探して添付」の 3 手間が、**キーを押す → ボタンを押す → Ctrl+V** になります。

## ほかのツールとどう違うか

- **オーバーレイを出しません。** ゲームや他のアプリに何も重ねず、何も注入しません。画面には常駐アイコンだけです
- **リプレイはメモリ上に持ちます。** 常時録画してディスクに書き続ける方式ではないので、保存していない間の書き込みはゼロです
- **ゲーミングノート(内蔵 GPU + 外部 GPU)でも動きます。** 画面を映す GPU と圧縮する GPU が別でも自動で切り替えます
- **共有までが 1 本に入っています。** 圧縮・結合・BGM・自動コピーまで込みです
- **設定は少なめです。** 長さ・画質・フレームレートを選んだら、あとは押すだけで使えます

配信したい、細かく作り込みたい、という用途なら **OBS** のほうが向いています。MOZU は「撮る・切る・投げる」に絞ったツールです。

## ダウンロード

[Releases](https://github.com/Luca001002/mozu/releases/latest) から `MOZU_x.y.z_x64-setup.exe` をダウンロードして実行してください。

- 対応 OS: Windows 10 / 11(64bit)
- 映像の圧縮には GPU のハードウェアエンコーダ(NVIDIA / AMD / Intel)を自動で使います

## はじめて使うとき

1. インストーラーの実行時に Windows SmartScreen の警告が出ることがあります(現在は署名なしで配布しているため)。「詳細情報」→「実行」で進めてください。
2. 起動後、設定画面でクリップ保存・スクショのショートカットキーを割り当ててください(初期状態では未割り当てです)。
3. インスタントリプレイを ON にすると記録が始まります。

## アップデート

新しいバージョンが出ると、アプリ内(トレイメニュー/設定の「このアプリについて」)にお知らせが表示されます。
クリックするとダウンロードして自動で入れ替わります。設定やクリップはそのまま残ります。
新しいインストーラーを直接実行して上書きしても構いません。

> ⚠️ アンインストール時に「アプリケーションデータを削除」へチェックを入れると設定が消えます。アップデート目的ならアンインストールは不要です。

## 不具合の報告

不具合を見つけたら、設定画面の「ログフォルダを開く」で開くフォルダ内のログファイル(`MOZU.log`)を添えて、**配布元へ直接ご連絡ください**。どんな操作をしたときに起きたかも書き添えてもらえると助かります。
